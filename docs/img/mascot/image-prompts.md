# Mascot Image Prompts: Pixel the Round-Face Robot

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

## Base Character Description

This is the core description included in full in every pose prompt below
so each one can be used independently:

```
A flat modern vector illustration of Pixel, a friendly pedagogical mascot
for the "Robot Faces: Drawing Expressive Displays for STEM Robots"
textbook. Pixel's entire head and body is a single circular color display
set inside a chunky rounded white bezel (hex #ECEFF1), with a thin
rainbow-gradient accent ring running around the outer edge. Two short,
jointed arms extend from the left and right sides of the disc, each
ending in a simple three-fingered rounded hand in vivid teal (hex
#00BFA5). Two stubby legs extend from the bottom of the disc, each ending
in a rounded foot, also teal. There is no separate torso — the circular
screen is both head and body. The face is drawn on the circular screen
using clean vector arcs: two round eyes with pupils, two
independently-angled eyebrows, and a mouth whose shape conveys emotion.
Pixel is small and compact, chibi-proportioned, icon-sized.
Style: flat modern vector illustration, clean bold outlines, soft
cel-shading, transparent background with alpha channel, suitable for
embedding in educational content. No text in image.
```
