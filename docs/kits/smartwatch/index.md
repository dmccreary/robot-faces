# Robot Faces Smartwatch Display

This kit is identical to our two button OLED kit with the exception that instead of using a square monochrome 128X64 OLED display, this kit uses a 2.1" round color TFT display with a resolutions of
240x240 or 360x360.

The big advantage of this kit is the low cost.  The display can be purchased for around $6 on sites like [AliExpress](./aliexpress-listing-gc9b72-2.1.png) and eBay
